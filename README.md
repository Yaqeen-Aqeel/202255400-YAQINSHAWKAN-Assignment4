## 📋 Project Description

This is a complete, responsive personal portfolio web application built with HTML, CSS, and JavaScript.
It showcases my background, technical projects, creative interests, and provides a way to get in touch.

The portfolio includes a range of interactive and dynamic features designed to create a polished,
professional user experience — including a personalized greeting, a live visit timer, an inspirational
quotes API, a validated contact form, a calligraphy gallery with a lightbox viewer, and more.

---

## ✨ Features

- **Responsive layout** — works seamlessly on all screen sizes (mobile, tablet, desktop)
- **Personalized greeting** — greets the visitor by name based on the time of day
- **Name memory** — visitor's name is saved and remembered using `localStorage`
- **Live visit timer** — shows how long the user has been on the page
- **Inspirational quotes** — fetched from the DummyJSON API with a "New Quote" button
- **Validated contact form** — checks for empty fields, email format, and highlights errors
- **Calligraphy gallery** — a responsive image grid showcasing personal calligraphy work
- **Lightbox viewer** — click any gallery image to view it fullscreen with a smooth overlay
- **Lazy loading** — all images use lazy loading for faster page performance
- **Error handling** — graceful fallback messages if the API fails

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Grid, responsive design)
- JavaScript (ES6+, async/await, localStorage, setInterval, DOM manipulation)
- [DummyJSON Quotes API](https://dummyjson.com/quotes/random)
