# AI Usage Report

**Project:** Personal Portfolio Web Application – Assignment 4  

---

## 1. Tools Used & Use Cases

### Claude (Anthropic)
I used Claude as my primary AI assistant throughout the assignment:
- Improve HTML structure for the portfolio to ease designing CSS
- Refine CSS layout, spacing, and responsive behavior
- Debug alignment and layout issues with project cards
- Implement the calligraphy gallery section with a responsive CSS Grid layout
- Implement the JavaScript lightbox feature (click-to-expand image viewer)
- Organize and draft the AI usage report, technical documentation, and README

### ChatGPT (OpenAI)
I used ChatGPT as a secondary reference tool:
- Review the implementation of the JavaScript greeting message based on time of day
- Help implement JavaScript modal behavior
- Implement advanced contact form validation with error highlights and fade messages
- Add and fix the visit duration counter feature
- Explain JavaScript concepts like async/await and localStorage

No code was copied blindly. All suggestions were reviewed, tested, and modified
to fit the assignment requirements.

---

## 2. Benefits & Challenges

### Benefits
- Saved time debugging CSS alignment and layout issues
- Improved my understanding of Flexbox, CSS Grid, and responsive design
- Learned how JavaScript interacts with HTML elements through practical examples
- Learned how to integrate external APIs and handle errors gracefully
- Helped produce more complete and professional documentation

### Challenges
- AI suggestions were sometimes too generic and needed significant modification
  to match the existing style and structure of my project
- Occasionally, Claude or ChatGPT suggested outdated practices (e.g., inline styles
  instead of CSS classes), which required manual correction
- There was a temptation to accept AI output without fully understanding it —
  I had to make a conscious effort to always read and test every suggestion first
- I had to test and tweak styles extensively to match the exact design I wanted

---

## 3. Learning Outcomes

From using AI, I learned:
- How Flexbox and CSS Grid control layout and spacing
- How CSS Grid's auto-fill with minmax() creates responsive layouts without media queries
- How to implement a lightbox from scratch using only vanilla JavaScript and CSS
- How to combine AI assistance with my own understanding to improve code quality
- How to use localStorage for state management
- The importance of reviewing AI output critically rather than accepting it blindly

---

## 4. Responsible Use & Modifications

All AI-generated suggestions were:
- Reviewed carefully line by line before being added to the project
- Tested in the browser and modified until they worked correctly in context
- Modified to match assignment requirements and my personal coding style
- Reformatted to maintain consistent indentation and naming conventions

This ensured originality, correctness, and academic integrity.
